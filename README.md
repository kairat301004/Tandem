# Tandem — корпоративная платформа
 
Backend корпоративной платформы для внутренней коммуникации сотрудников: новости компании, задачи, чаты в реальном времени, файлы, уведомления и администрирование пользователей.
 
Построен на **Spring Boot 3** и **Java 21**, данные хранятся в **PostgreSQL**, схема БД управляется через **Liquibase**, обмен сообщениями в реальном времени — по **WebSocket (STOMP)**.
 
---
 
## Возможности
 
- **Аутентификация** — вход по email и паролю, сессии на основе `JSESSIONID`, пароли хранятся в BCrypt.
- **Роли и права** — гибкая модель доступа: у роли есть набор прав (`Permission`), проверка через `@PreAuthorize`.
- **Новости** — создание (JSON или multipart с вложениями), просмотр, редактирование и удаление. Автор может управлять своими новостями без дополнительных прав.
- **Задачи** — создание, назначение, смена статуса, приоритеты, список «мои задачи».
- **Чаты** — личные и групповые чаты, добавление участников, выход из чата, сообщения с файлами, отметка о прочтении, поиск по сообщениям.
- **Уведомления** — хранение в БД и мгновенная доставка через WebSocket, счётчик непрочитанных.
- **Файлы** — загрузка, скачивание, удаление (до 50 МБ), аватары пользователей.
- **Профиль** — редактирование профиля, смена пароля, загрузка аватара, поиск сотрудников.
- **Админ-панель** — управление пользователями, сброс пароля, роли, отделы.
- **Swagger UI** — интерактивная документация API.
## Технологии
 
| Категория | Стек |
|---|---|
| Язык | Java 21 |
| Фреймворк | Spring Boot 3.3.5 (Web, Data JPA, Security, Validation, WebSocket, Cache) |
| База данных | PostgreSQL 15 |
| Миграции | Liquibase |
| Кэш | Redis 7 |
| Маппинг | MapStruct, Lombok |
| Документация API | springdoc-openapi (Swagger UI) |
| Сборка | Maven (wrapper в комплекте) |
| Контейнеризация | Docker, Docker Compose |
 
 
## Быстрый старт
 
### Docker Compose (всё сразу)
 
```bash
git clone https://github.com/kairat301004/Tandem.git
cd Tandem
docker compose up --build
```
 
Поднимутся три контейнера:
 
| Сервис | Адрес |
|---|---|
| Приложение | http://localhost:8080 |
| PostgreSQL | `localhost:5433` (БД `corp_platform`, `postgres` / `postgres`) |
| Redis | `localhost:6379` |
 
Liquibase автоматически создаст все таблицы при первом старте.
 
 
## API
 
После запуска документация доступна по адресу:
 
- Swagger UI: http://localhost:8080/swagger-ui/index.html
- OpenAPI JSON: http://localhost:8080/v3/api-docs
